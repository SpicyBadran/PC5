The x64 and ia32 artifacts are from *separate* gate runs, deliberately: the gate writes its
serial logs to $(BUILD)/ovmf-serial for whichever profile it is testing, so a 32-bit run in the
same build directory overwrites the 64-bit evidence.  The 64-bit run was repeated into
BUILD=/tmp/m8iso so the two sets could not be confused -- and the first copy made here *was*
the wrong profile, which is how that became known.
